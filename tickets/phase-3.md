# Phase 3 — AI 코치 (구독)

목표: 연습 기록 → 타겟 궤적 대비 진행 판단 + 향상 가속도 + 다음 연습 포커스.
수영 폼/기술 코칭이 아니라 **기록 궤적 코칭**이다. 계약: `common/api-spec.md` §ai-coach.

## T-301 구독
- RevenueCat(iOS/Android IAP 통합) → 웹훅으로 `Entitlements` 테이블 갱신.
- 모든 구독 전용 API는 entitlement 미들웨어로 보호(클라이언트 신뢰 금지).
- 수용: 샌드박스 구매→해지 시나리오에서 API 접근이 열리고 닫힘.

## T-302 ai-coach 서비스
- 결정적 분석(코드): 이벤트별 시계열 회귀로 개선 기울기(초/주), 기울기의 변화 =
  **가속도**, 타겟 도달 예상일, on-track 판정(타겟 날짜까지 필요한 기울기와 비교),
  구간 페이스 일관성(스플릿 표준편차 추세).
- LLM(Bedrock Claude): 위 수치를 입력으로 연습 요약·다음 포커스 문장 생성(수치는
  LLM이 계산하지 않음 — 환각 방지).
- API: `GET /coach/analysis/{swimmerId}?event=`, `POST /coach/session-review`.
- 수용: 합성 데이터 3종(향상/정체/퇴보)에 대해 판정 스냅샷 테스트.

## T-303 앱: AI 코치 화면
- 타겟까지 진행률 게이지 + 예상 도달일, 가속도 배지(↑개선 가속/→유지/↓둔화),
  세션 저장 직후 1줄 리뷰, 주간 리포트.
- 무료 사용자에게는 잠금 미리보기(업셀).

## T-304 포트폴리오
- 에이지 그룹 표준 사다리(B→AAAA) 위 위치 히스토리 + 시즌 랭킹 근사치(표준 대비
  백분위). 에이지업 되어도 과거 과정이 그대로 남는 타임라인.
- 공유 카드(이미지) 내보내기 — 리크루팅/클럽 이동 시 포트폴리오.

## T-305 AI 가이드 엔진(수영·진학) [done — 결정적 엔진]
`services/ai-coach` — **수치는 코드가, 문장은 LLM이** 원칙의 결정적 계층.
- **수영 코치**(`swim-guidance.ts`): best 타임 → 표준 레벨 → tier 판정,
  나이대(LTAD 근사)별 주간 플랜·집중 포인트·유튜브 학습 링크·안전 고지.
- **진학 코치**(`college-guidance.ts`): 운동 tier + 학업 백분위(수학·ELA) + AP +
  활동 → 학교 reach/match/safety + 나이별 로드맵 + 학교별 개인화 준비 제안.
  ⚠️ 학교 프로필은 공개 통념 기반 **시드**(공식 입학 데이터로 교체 예정).
- 테스트: swim 5 + college 5. Bedrock은 이 구조화 결과 위에 자연어 문장만 생성.
