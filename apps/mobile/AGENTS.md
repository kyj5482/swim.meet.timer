# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.

**SDK 고정 사유**: Expo Go 앱이 최신 SDK 57을 아직 지원하지 않아(스토어 배포
지연) 56.0.13으로 고정했다. Expo Go로 QR 스캔 테스트가 필요하므로, 스토어의
Expo Go 앱이 지원하는 SDK와 항상 맞춰야 한다 — `expo`를 올릴 때는 반드시
Expo Go 앱의 최신 지원 SDK를 먼저 확인할 것.
