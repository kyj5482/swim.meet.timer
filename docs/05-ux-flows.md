# 05. 화면 구성 & UX 플로우

메인은 **① 타이머**와 **② 기록지** 두 화면. 타이머는 _설정 → 측정 → 선수 배정_ 3단계로 흐른다.

> 실제 동작은 [`design-preview/timer.html`](./design-preview/timer.html)에서 확인. 이 문서의 ASCII는 그 구현과 일치한다.

---

## 5.1 정보 구조 (IA)

```
앱
├─ 타이머 탭
│   ├─ ① 설정   (코스/종목/거리 + 인원 +/-)
│   ├─ ② 측정   (러닝 클락 + 단일 LAP + 익명 슬롯 카드)
│   └─ ③ 배정   (기록 → 선수 추천 · 향상 체크 · 저장)
├─ 기록지 탭
│   ├─ 선수 목록(로스터)
│   └─ 선수 상세 (세션 목록 · 스플릿 · 베스트 · 추세)
└─ 설정 (단위 기본값, 사운드/햅틱, 내보내기)
```

> **핵심 전환(v2)**: 선수는 *출발 전*이 아니라 *측정 후*에 배정한다. 측정 중엔 익명 슬롯(1번·2번·…)만 다룬다. [02 §2.8]

---

## 5.2 화면 ① — 설정 (Setup)

목적: **무엇을, 몇 명** 측정할지 30초 안에.

```
┌──────────────────────────────┐
│ 100y 자유형 · 25y      ● 화면유지 │
│ ┌ 25m ┐┌▣25y▣┐┌ 50m ┐         │  코스 토글 (FR-S1)
│ 종목 [ 자유형      ▾ ]          │
│ 거리 [ 100        ▾ ]          │
│ 구간 4개 · 100y ÷ 25            │  세그먼트 자동 계산 (FR-S2)
│ ┌──────────────────────────┐ │
│ │ 인원        [ − ] 3 [ + ] │ │  +/- 스테퍼 (FR-S3)
│ └──────────────────────────┘ │
│ 익명 슬롯으로 측정 → 끝난 뒤 배정  │
│                                │
│ ┌──────────────────────────┐ │
│ │          START            │ │  하단 풀폭 (NFR-6)
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- 거리가 구간으로 **나눠떨어지지 않으면** 인라인 경고 + START 비활성(FR-S2).
- 슬롯별 종목/거리 오버라이드(FR-S4, 접힘 기본), 프리셋 저장(FR-S5, P1).
- 출발 전 선수 지정 없음 — **인원 수만** 정한다.

## 5.3 화면 ② — 측정 (Timing, 핵심)

```
┌──────────────────────────────┐
│           00:26.80            │  러닝 클락 · 1/100초 (FR-T2)
│   랩 6 / 12 · 남은 선수 3명       │  진행도 (FR-T9)
├──────────────────────────────┤
│ ▌1번        ●●○○   :12.95 :13.05│  익명 슬롯 카드(색+번호+도트)
│ ▌2번  ←펄스 ●●○○   :12.80 :13.10│  방금 배정 하이라이트 (FR-T5)
│ ▌3번        ●●○○   :13.60 :13.90│
├──────────────────────────────┤
│ 방금 배정 정정 →  (1) (2) (3)    │  슬롯 칩 (FR-T6)
│ ┌──────────────────────────┐ │
│ │           L A P           │ │  단일 대형 버튼 (FR-T3)
│ └──────────────────────────┘ │
│   [ ↶ Undo ]      [ ⟲ 리셋 ]   │
└──────────────────────────────┘
```

상호작용:
1. **START** → t0 캡처, 버튼이 `LAP`으로 전환.
2. **LAP**: 누를 때마다 익명 슬롯에 자동 배정(§3.3). 배정 슬롯 카드가 **그 색으로 0.6s 펄스 + 햅틱**.
   - 1라운드: 벽 찍는 순서가 슬롯 1·2·3을 정의. 이후: 각 슬롯의 자기 페이스로 추적.
3. **재할당**: 방금 배정이 틀리면 하단 **슬롯 칩(1/2/3)** 1탭(FR-T6). 시계는 안 멈춤.
4. **Undo**: 중복/오탭 취소(FR-T10).
5. **완주**: 슬롯이 마지막 도트를 채우면 "완주 52.30" 잠금, 후보 제외(FR-T7).
6. **종료**: 모든 슬롯 완주 시 자동으로 **배정 화면**으로 전환(FR-T8).

마이크로 카피: 색·번호·도트·숫자 **다중 인코딩**으로 색맹 대응(NFR-8).

## 5.4 화면 ③ — 선수 배정 + 향상 체크 (Assign)

코치의 "훈련 끝, 누가 늘었나" 확인 지점.

```
┌──────────────────────────────┐
│ 기록 완료 — 선수 배정             │
│ 🎉 향상 2명  🏅 PB 2명  총 3명    │  요약 헤드라인 (FR-A5)
├──────────────────────────────┤
│ ▌1번                   52.40   │
│  [ 민준            ▾ ]  (추천)   │  추천 미리채움 (FR-A2)
│  ⚠ 2번과 0.10초 차 — 확인 [↔맞바꾸기]│  저신뢰 안전장치 (FR-A4)
│  이전 53.40 → 52.40 ▼1.00 🏅PB   │  향상 체크 (FR-A3)
│  [25y 12.95][50y 13.05][75y …]  │  구간 스플릿
├──────────────────────────────┤
│ ▌3번                   55.90   │
│  [ 도윤            ▾ ]  (추천)   │
│  이전 56.00 → 55.90 ▼0.10 🏅PB   │
│  …                              │
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │         기록 저장          │ │  트랜잭션 저장 (FR-A6)
│ └──────────────────────────┘ │
│ [ 다시 측정 ]                   │
└──────────────────────────────┘
```

- **추천**: 기록된 타임 ↔ 선수 이력 전역 최소비용 매칭(§3.6). 드롭다운으로 변경 가능.
- **향상 체크**: `이전 → 오늘` + ▼/▲ 증감, 베스트 경신 시 🏅PB.
- **모호성**: 두 슬롯 기록이 가까우면(<0.40초) 앰버 경고 + **원탭 맞바꾸기**. 저신뢰 PB는 흐리게(§3.5a).
- **저장**: 슬롯마다 해당 선수 기록지에 1건 append. 토스트 "N명 기록 저장됨".

---

## 5.5 화면 ④ — 기록지 (선수 목록 / 상세)

- **목록**: 선수 카드(이름·최근 측정일·최근 종목). 검색/그룹 필터. `+ 선수 추가`.
- **상세**:
  - 상단: 베스트 타임 배지(종목/거리별), 추세 미니 그래프(P1).
  - 본문: 세션 리스트(날짜·세트·총기록). 펼치면 세그먼트 스플릿·구간 일관성.
  - 액션: 메모, 수정/삭제, 공유/CSV(P1).

---

## 5.6 핵심 사용자 여정 (Happy Path)

```
코치: 25y 선택 → 100 free → 인원 3 (+/-)
   → [START] → 선수들 벽 찍는 순서대로 LAP·LAP·LAP … (12탭)
   → 가끔 순서 틀리면 슬롯칩 1탭으로 정정
   → 마지막 탭 = 자동 종료 → 배정 화면
   → 추천 확인(비슷하면 ↔맞바꾸기) → "민준 PB!" 한눈 확인 → 저장
   → 기록지에 3명 자동 누적. 수기 정리 0.
```

## 5.7 상태/엣지 UX

| 상황 | UX |
| --- | --- |
| 화면 꺼짐 방지 | 측정 중 Wake Lock, 상단 "화면 유지" 미세 표시(NFR-4). |
| 크래시 복구 | 재실행 시 "측정 복구하시겠어요?" 배너(NFR-7). |
| 신규 선수(이력 없음) | 배정 드롭다운에서 직접 선택, "기준 기록 없음"이면 향상치 생략. |
| DNF | 슬롯 카드 길게 눌러 "이 슬롯 종료(DNF)". |
| 잘못된 거리/구간 | 설정 화면 인라인 경고, START 비활성. |
| 측정 중 인원 변경 | 확인 → 타이머 리셋(FR-S6). |
