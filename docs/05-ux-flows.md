# 05. 화면 구성 & UX 플로우

메인은 **① 타이머**와 **② 기록지** 두 화면. 타이머는 _설정 → 측정 → 선수 배정_ 3단계로 흐른다.

> 실제 동작은 [`design-preview/timer.html`](./design-preview/timer.html)에서 확인. 이 문서의 ASCII는 그 구현과 일치한다.

---

## 5.1 정보 구조 (IA)

```
앱
├─ 타이머 탭
│   ├─ ① 설정   (코스/종목/거리 + 인원 +/-)
│   ├─ ② 측정   (러닝 클락 + 단일 LAP + 익명 슬롯 카드)
│   └─ ③ 배정   (기록 → 선수 추천 · 향상 체크 · 저장)
├─ 기록지 탭
│   ├─ 선수 목록(로스터)
│   └─ 선수 상세 (세션 목록 · 스플릿 · 베스트 · 추세)
└─ 설정 (단위 기본값, 사운드/햅틱, 내보내기)
```

> **핵심 전환(v2)**: 선수는 *출발 전*이 아니라 *측정 후*에 배정한다. 측정 중엔 익명 슬롯(1번·2번·…)만 다룬다. [02 §2.8]

---

## 5.2 화면 ① — 설정 (Setup)

목적: **무엇을, 몇 명** 측정할지 30초 안에.

```
┌──────────────────────────────┐
│ 100y 자유형 · 25 Yard         ⚙ │  헤더 표시 + 설정(⚙)
│ ┌ 코스  25 Yard   설정에서 변경┐│  코스 표시만(전체이름) (FR-S1)
│ 종목  [ 자유형        ▾ ]       │
│ 거리  [ 100          ▾ ]       │
│ 스플릿 [ 25 Yard마다   ▾ ]      │  스플릿 간격 선택 (FR-S2b)
│ 구간 4개 · 25 Yard마다 LAP      │
│ ┌──────────────────────────┐ │
│ │ 인원        [ − ] 3 [ + ] │ │  +/- 스테퍼 (FR-S3)
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │          START            │ │  하단 풀폭 (NFR-6)
│ └──────────────────────────┘ │
└──────────────────────────────┘
설정 시트(⚙): 코스 [25 Meter][25 Yard][50 Meter]  "한 번 설정 → 모든 측정"
```

- **코스는 설정에서 한 번만** 정하고 보존, **전체 이름**으로 표시(FR-S1).
- **스플릿 간격 선택**(FR-S2b): `25 Yard마다`(4구간)/`50 Yard마다`(2구간)/`전체·1회`. 25Y풀 50자유형은 결과 1회도 가능.
- 거리가 풀 길이로 **나눠떨어지지 않으면** 인라인 경고 + START 비활성(FR-S2).
- 슬롯별 종목/거리 오버라이드(FR-S4, 접힘 기본), 프리셋 저장(FR-S5, P1).
- 출발 전 선수 지정 없음 — **인원 수만** 정한다.

## 5.3 화면 ② — 측정 (Timing, 핵심)

**무스크롤 앱셸**: 시계(상단 고정) · 레인 행(가운데, 일반 인원은 스크롤 없음) · LAP(하단 고정).
시계는 **큰 `MM:SS` + 작은 `.SS`(1/100초)** 로 화면 안에 확실히 들어온다(FR-T2).

```
┌──────────────────────────────┐
│        00:26 .80              │  큰 MM:SS + 작은 1/100초
│  랩 6/12 · 남은 3명 · 레인 탭/LAP  │  진행도 (FR-T9)
├──────────────────────────────┤
│ ▌1번          ●●○○  :12.95 :13.05│  레인 행=큰 탭 타깃 · 스플릿 최근 4개 표시
│ ▌2번 [다음]    ●●○○  :12.80 :13.10│  ← 예측된 다음 도착 레인 강조
│ ▌3번          ●●○○  :13.60 :13.90│
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │           L A P           │ │  단일 대형 버튼 (FR-T3)
│ │      다음 예측 ▸ 2번         │ │  예측 레인 표시
│ └──────────────────────────┘ │
│   [ ↶ 실행취소 ]     [ ⟲ 리셋 ]  │
└──────────────────────────────┘
```

상호작용 — **두 가지 입력, 한 동작 수준**(알고리즘 한계를 UI로 보완: [07], [03 §3.4]):
1. **START** → t0 캡처, 버튼이 `LAP`으로 전환.
2. **LAP(예측)**: 누르면 **예측된 다음 레인**에 기록(버튼에 `다음 ▸ N번` 표시). 잘 맞는 일반 상황은 화면 안 보고 리듬만.
3. **볼륨키/스페이스**로도 LAP(시선을 물에, eyes-free, FR-T3c).
4. **레인 행 직접 탭(WYSIWYG)**: 방금 벽 찍은 레인을 코치가 *본 대로* 탭 → 그 레인에 기록. **순서 역전·초접전에서도 100% 정확**. 풀폭 대형 타깃이라 오탭 적음.
5. 기록된 레인 카드가 **그 색으로 0.6s 펄스 + 햅틱**. 1라운드 도착 순서가 슬롯을 정의.
6. **실행취소**: 중복/오탭 취소(FR-T10).
7. **완주**: 슬롯이 마지막 도트를 채우면 "완주 52.30" 잠금(FR-T7).
8. **종료**: 모든 슬롯 완주 시 자동으로 **배정 화면**으로 전환(FR-T8).

마이크로 카피: 색·번호·도트·숫자 **다중 인코딩**으로 색맹 대응(NFR-8). 로드맵: **볼륨 버튼** 조작으로 eyes-free([07]).

## 5.4 화면 ③ — 선수 배정 + 향상 체크 (Assign)

코치의 "훈련 끝, 누가 늘었나" 확인 지점.

```
┌──────────────────────────────┐
│ 기록 완료 — 선수 배정             │
│ 🎉 향상 2명  🏅 PB 2명  총 3명    │  요약 헤드라인 (FR-A5)
├──────────────────────────────┤
│ ▌1번                   52.40   │
│  [ 민준            ▾ ]  (추천)   │  추천 미리채움 (FR-A2)
│  ⚠ 2번과 0.10초 차 — 확인 [↔맞바꾸기]│  저신뢰 안전장치 (FR-A4)
│  이전 53.40 → 52.40 ▼1.00 🏅PB   │  향상 체크 (FR-A3)
│  [25y 12.95][50y 13.05][75y …]  │  구간 스플릿
├──────────────────────────────┤
│ ▌3번                   55.90   │
│  [ 도윤            ▾ ]  (추천)   │
│  이전 56.00 → 55.90 ▼0.10 🏅PB   │
│  …                              │
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │         기록 저장          │ │  트랜잭션 저장 (FR-A6)
│ └──────────────────────────┘ │
│ [ 다시 측정 ]                   │
└──────────────────────────────┘
```

- **추천**: 기록된 타임 ↔ 선수 이력 전역 최소비용 매칭(§3.6). 드롭다운으로 변경 가능.
- **향상 체크**: `이전 → 오늘` + ▼/▲ 증감, 베스트 경신 시 🏅PB.
- **모호성**: 두 슬롯 기록이 가까우면(<0.40초) 앰버 경고 + **원탭 맞바꾸기**. 저신뢰 PB는 흐리게(§3.5a).
- **＋ 새 선수 추가**(FR-A7): 명단에 없으면 시트(이름·그룹)로 즉시 추가 → 해당 슬롯 배정. 이력 없으면 "첫 기록".
- **저장**: 슬롯마다 해당 선수 기록지에 1건 append. 토스트 "N명 기록 저장됨".

## 5.5 화면 ④ — 기록지 (Records)

```
┌──────────────────────────────┐
│ 민준 · 엘리트반                  │
│ 종목 선택 (좌우 스와이프)          │
│ [100자유 52.40▼][50자유 25.10▼][100배영…] │  종목 베스트=버튼, 가로 스크롤 (FR-R2)
│ ┌ 100 자유형 추세 ───────────┐ │
│ │   (시계열 라인, PB 표시)       │ │  선택 종목 추세 (FR-R3)
│ └──────────────────────────┘ │
│ 세션 기록      2개+ 선택→구간비교  │
│ ☐ 06-17  PB        52.40      │  히스토리(선택 가능)
│ ☑ 06-12            52.82      │
│ ☑ 06-05            53.24      │
│ …                              │
│ ┌──────────────────────────┐ │
│ │      구간 비교 (2개)         │ │  하단 sticky (FR-R4)
│ └──────────────────────────┘ │
└──────────────────────────────┘
  팝업: 구간별 스플릿 비교(세션별 색 라인 + 표, 구간 최속 강조)
```

- **종목 선택**(FR-R2): 종목별 베스트 카드를 **버튼**으로, 종목 많아 **가로 스크롤/스와이프**. 베스트 UI 유지.
- **선택 종목 상세**(FR-R3): 시계열 추세(총기록, 낮을수록 위·PB 강조) + 세션 히스토리 목록.
- **구간 비교**(FR-R4): 히스토리 **2개 이상 체크** → 하단 `구간 비교` → **팝업**에 구간별 스플릿 라인 그래프 + 표(세션별 색, 구간 최속 초록). "어느 구간에서 빨라졌나" 분석.
- 선수 추가는 **＋ 새 선수 추가** 시트(FR-A7) 공용. 메모·수정/삭제·공유·CSV(P1).

## 5.6 핵심 사용자 여정 (Happy Path)

```
코치: 25y 선택 → 100 free → 인원 3 (+/-)
   → [START] → 선수들 벽 찍는 순서대로 LAP·LAP·LAP … (12탭)
   → 가끔 순서 틀리면 해당 레인을 직접 탭(또는 볼륨키로 LAP)
   → 마지막 탭 = 자동 종료 → 배정 화면
   → 추천 확인(비슷하면 ↔맞바꾸기) → "민준 PB!" 한눈 확인 → 저장
   → 기록지에 3명 자동 누적. 수기 정리 0.
```

## 5.7 상태/엣지 UX

| 상황 | UX |
| --- | --- |
| 화면 꺼짐 방지 | 측정 중 Wake Lock, 상단 "화면 유지" 미세 표시(NFR-4). |
| 크래시 복구 | 재실행 시 "측정 복구하시겠어요?" 배너(NFR-7). |
| 신규 선수(이력 없음) | 배정 드롭다운에서 직접 선택, "기준 기록 없음"이면 향상치 생략. |
| DNF | 슬롯 카드 길게 눌러 "이 슬롯 종료(DNF)". |
| 잘못된 거리/구간 | 설정 화면 인라인 경고, START 비활성. |
| 측정 중 인원 변경 | 확인 → 타이머 리셋(FR-S6). |
