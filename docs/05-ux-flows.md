# 05. 화면 구성 & UX 플로우

메인은 **① 타이머**와 **② 기록지** 두 화면. 그 사이를 세션 설정과 저장 확인이 잇는다.

---

## 5.1 정보 구조 (IA)

```
앱
├─ 타이머 탭
│   ├─ 세션 설정 (코스/종목/거리/레인·선수 추천)
│   ├─ 측정 화면 (러닝 클락 + 단일 버튼 + 레인 카드)
│   └─ 저장 확인 (REVIEW)
├─ 기록지 탭
│   ├─ 선수 목록(로스터)
│   └─ 선수 상세 (세션 목록 · 스플릿 · 베스트 · 추세)
└─ 설정 (단위 기본값, 사운드/햅틱, 내보내기)
```

---

## 5.2 화면 A — 세션 설정

목적: 출발 전 **무엇을·누가** 측정할지 1분 안에 구성.

- 상단: **코스 토글** `25m | 25y | 50m`, **종목**, **총 거리**(→ 세그먼트 수 자동 표시: "100y ÷ 25y = 4구간").
- 중앙: **레인 리스트(1..N)**. 각 레인에 추천 선수 칩(FR-S4). 탭하면 대안 선수/검색.
  - 레인별 종목·거리 오버라이드 토글(접힘 기본).
- 하단: 큰 **`출발 준비`** → 측정 화면. 자주 쓰면 **프리셋 저장**.
- 규칙: 측정 시작 후 이 화면에서 선수를 바꾸면 → 확인 → **리셋**(FR-S6).

---

## 5.3 화면 B — 측정 (핵심)

레이아웃(모바일 세로):

```
┌──────────────────────────────┐
│        00:48.6   ← 러닝 클락(대형)  │  전체 경과(FR-T2)
│        100y free · 25y         │
├──────────────────────────────┤
│ � L1  민준   2/4  ●●○○          │  레인 카드: 색·이름·진행·스플릿
│      :12.8  :13.1              │
│ ▣ L2  서연   2/4  ●●○○   ← 방금배정 하이라이트
│      :13.0  :13.4              │
│ �auto L3 하준  1/4  ●○○○         │
│      :13.5                     │
├──────────────────────────────┤
│   [↶ Undo]      [⤺ L1 L2 L3]   │  재할당 칩(FR-T6)
│ ┌──────────────────────────┐ │
│ │           L A P           │ │  단일 대형 버튼(FR-T3, NFR-6)
│ └──────────────────────────┘ │
│  [⏸ 일시정지]        [⟲ 리셋]    │
└──────────────────────────────┘
```

상호작용:
1. **Start**: 첫 진입 시 버튼이 `START`. 누르면 t0 캡처, 버튼이 `LAP`으로 전환.
2. **Lap**: 누를 때마다 자동 배정(§3.3). 배정된 레인 카드가 **그 레인 색으로 0.6s 펄스 + 햅틱**.
   - 카드에 방금 스플릿(:12.8)과 진행 도트(●●○○) 즉시 갱신.
3. **재할당**: 방금 배정이 틀리면 하단 **레인 칩**(L1/L2/L3)에서 올바른 레인 1탭(FR-T6).
4. **Undo**: 중복/오탭 시 직전 탭 취소(FR-T9).
5. **완주**: 한 레인이 마지막 도트를 채우면 카드가 "완주 12:53" 상태로 잠금, 버튼/배정 후보에서 제외(FR-T7).
6. **종료**: 모든 레인 완주 시 자동으로 **저장 확인**으로 전환(FR-T8).

마이크로 카피/피드백:
- 버튼 라벨은 상태로 명확히: `START` → `LAP` → (마지막) 자동 종료.
- 색·도트·숫자 **3중 인코딩**으로 색맹 대응(NFR-8).

---

## 5.4 화면 C — 저장 확인 (REVIEW)

- 레인별 스플릿 표(누적/구간), 총 기록, 완주/DNF.
- 잘못된 값 **탭해서 수정**, 누락 **삽입**, 레인 간 split **이동**.
- 선수 매핑 최종 확인(여기서 바꿔도 됨 — 이미 종료 상태라 리셋 아님).
- **저장** → 각 선수 기록지에 append(FR-R1), 토스트 "3명 기록 저장됨". **다시 측정**(같은 세트 재시작) 단축 제공.

---

## 5.5 화면 D — 기록지 (선수 목록 / 상세)

- **목록**: 선수 카드(이름·최근 측정일·최근 종목). 검색/그룹 필터. `+ 선수 추가`.
- **상세**:
  - 상단: 베스트 타임 배지(종목/거리별), 추세 미니 그래프(P1).
  - 본문: 세션 리스트(날짜·세트·총기록). 펼치면 세그먼트 스플릿·구간 일관성.
  - 액션: 메모, 수정/삭제, 공유/CSV(P1).

---

## 5.6 핵심 사용자 여정 (Happy Path)

```
코치: 25y 선택 → 100 free → 레인1 민준/레인2 서연/레인3 하준(추천 수락)
   → [출발 준비] → 측정화면 [START]
   → (출발) 선수들 25y 터치 순서대로 LAP·LAP·LAP …
   → 가끔 순서 틀리면 레인칩 1탭으로 정정
   → 마지막 선수 100y 터치 = 자동 종료 → REVIEW(슥 확인) → 저장
   → 기록지에 3명 기록 자동 누적. 수기 정리 0.
```

## 5.7 상태/엣지 UX

| 상황 | UX |
| --- | --- |
| 화면 꺼짐 방지 | 측정 중 Wake Lock, 상단에 "화면 유지 중" 미세 표시(NFR-4). |
| 크래시 복구 | 재실행 시 "측정 복구하시겠어요?" 배너(NFR-7). |
| 신규 선수(이력 없음) | 배정은 기본 페이스로, 카드에 "기준 기록 없음" 라벨. |
| DNF | 레인 카드 길게 눌러 "이 레인 종료(DNF)". |
| 잘못된 거리/구간(나눠떨어지지 않음) | 설정 화면에서 인라인 경고, 출발 비활성. |
