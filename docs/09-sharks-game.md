# 09 — 이스터 에그: Sharks in the Water! (웹 게임)

참고 영상: https://www.youtube.com/watch?v=LX-phYsiMdg ·
https://www.youtube.com/watch?v=uqD_MftRRx4 (Danny Go! 스타일 — 3인칭 후방 시점,
바닷속을 헤엄쳐 보물섬까지 가는 장애물 회피). 목표 퀄리티: Pet Runner 수준의
UI·게임 시나리오.

## 1. 트리거 (이스터 에그)

- 타이머 측정 종료 후 **선수 배정(assign) 화면**에서, 어떤 슬롯이든 최종 기록의
  **1/100초 두 자리가 같은 숫자**(`.x00`, `.x11` … `.x99`)면 활성화.
  - 판정: `cs = floor(ms / 10) % 100; cs % 11 === 0`.
- 활성화 시 "+ Add Swimmer" 버튼 **아래**에 `🦈 Sharks in the Water!` 버튼 표시.
- 버튼 → 앱 내 웹뷰(`/game` 라우트) 풀스크린. 타이머에서 선택한 **영법·거리·코스
  단위가 그대로 게임 설정**으로 주입된다.

## 2. 게임 규칙 (영상과 동일한 뼈대 + 확장)

3인칭 후방 시점(마리오 카트 수중 테마 느낌). 캐릭터는 화면 하단 중앙, 장애물이
수평선에서 다가온다. **레인 3열(좌/중/우) × 깊이 3단(수면/중간/바닥)** 그리드.

### 조작
- 스와이프 좌/우: 레인 이동. 스와이프 위/아래: 깊이 이동(위=떠오르기, 아래=duck).
- 이동은 항상 **선택한 영법의 수영 모션**으로 애니메이션(아래 §5).
- **1초 길게 누르기**: 상어 경보 중이면 바위섬 위로 대피. 상어가 지나가면 다시
  1초 홀드로 입수 — 이때 물방울(버블) 물보라 화면 전환.
- 최종 스프린트 구간: 연타(탭)로 가속.

### 진행 구조 (거리 = 타이머 거리, 예: 50yd)
- 화면에 **Lap x/N + 경과 시간(1/100초) + 진행 바 + 코인** HUD.
- Lap 수 = `distance / 25`(최소 1, 최대 8). Lap마다 진행 속도 +8% (점점 어려움).
- **IM**은 실제 경기 순서로 Lap을 4등분해 접영→배영→평영→자유형 자동 전환.
- 거리(랩 수)에 따라 씨월드 테마 구간이 바뀐다(§4).

### 장애물 (닿으면 게임 오버)
1. **다가오는 생물**: 해파리 무리·복어·바다뱀 — 특정 레인·깊이를 막는다. 바로
   앞까지 와서 피하면 되는 타이밍 게임.
2. **산호 동굴 게이트**: 아치 3개 중 **1개만 통과 가능**. 못 가는 아치는 문어
   다리·성게 등으로 막혀 있음(색·실루엣 힌트). 통과 레인으로 미리 이동해야 함.
3. **상어**: 원거리에서는 흐릿한 실루엣(블러·저채도)이라 일반 장애물에 시선이
   가 있으면 놓치기 쉽다. 가까워져 실루엣이 선명해지는 순간 "SHARKS IN THE
   WATER!" 경보 — **1초 홀드로 바위 대피만이 생존법**. 경보 후 유예 시간 안에
   대피 못 하면 게임 오버.
4. 보물 구간: 바닥에 흩어진 **코인·보석** 수집(§3 보스 조건).

### 상어왕 보스전
- 코인+보석 **12개 이상** 모은 상태로 보스 구간 도달 시 발동.
- 제자리(고정) — 상어왕이 던지는 씨월드 투사체(뼈다귀·성게·먹물)를 **골키퍼처럼
  3×3 그리드로 회피**. 10회 투척 생존이 목표.
- **회피 성공 시간에 비례해 최종 수영 시간 단축**(회피 1회당 −0.8초 보너스).
- 피격 시 보스전 종료(게임 오버 아님 — 보너스만 종료)하고 레이스 복귀.

### 최종 스프린트
- 마지막 Lap 종반: 바위가 더 없고 상어 무리가 추격. **연타로 가속**해 보물섬
  도착. 도착 연출(보물 더미) 후 결과 화면.

## 3. 기록·리더보드·배지

- 최종 기록 = 실제 플레이 경과 시간 − 보스전 보너스 (ms 정수).
- 로그인 사용자는 `(stroke, distance, course)` 키로 서버에 기록 제출 →
  **등수**와 **백분위 배지** 표시. 배지는 표준기록 레벨과 같은 사다리:

| 배지 | 백분위(상위) |
| --- | --- |
| AAAA | 1% |
| AAA | 5% |
| AA | 15% |
| A | 30% |
| BB | 50% |
| B | 나머지 |

- API 계약: `common/api-spec.md` §game. 비로그인은 로컬 결과만 표시.

## 4. 씨월드 테마 (Lap 구간별)

1. **Sunlit Reef** — 밝은 산호초, 해파리·물고기 떼. (모든 거리의 시작)
2. **Kelp Forest** — 켈프 기둥 슬라럼, 복어.
3. **Shipwreck** — 난파선 잔해, 산호 동굴 게이트, 보물 구간.
4. **Deep Cave** — 어둡고 시야 좁음(라이트 콘), 바다뱀·성게. 보스 구간.
5. **Treasure Shallows** — 최종 스프린트 → 보물섬.

거리별 매핑: 25→[1,5], 50→[1,3,5], 100→[1,2,3,5], 200+→[1,2,3,4,5] (구간을
Lap 수에 비례 배분). 상어 이벤트는 테마 전환부마다 1회 + 랜덤.

## 6. 구현 구조

- 게임: **의존성 0의 단일 HTML**(canvas 2D) —
  `apps/mobile/src/features/game/game.html`(소스) →
  `npm run build:game -w apps/mobile` 이
  `src/features/game/gameHtml.ts`(생성물, 커밋함)로 인라인.
- 웹뷰: `react-native-webview`, `source={{ html }}`. 파라미터는
  `injectedJavaScriptBeforeContentLoaded`로 `window.GAME_CONFIG =
  { stroke, distance, courseUnit, player?, leaderboard? }` 주입.
- 결과: 게임이 `window.ReactNativeWebView.postMessage(JSON{type:'result',
  timeMs, coins, outcome})` → RN이 로그인 시 서버 제출, 응답(rank/badge/total)을
  `postResult(...)`로 웹뷰에 재주입.
- 이스터 에그 감지는 순수 함수 `sharksEgg.ts`(+vitest).
- 서버: records 서비스에 `/game/scores`·`/game/leaderboard` 추가.
