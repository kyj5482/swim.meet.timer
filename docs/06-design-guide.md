# 06. 디자인 가이드 (Design Guide)

컨셉: **"Poolside Stopwatch."** 깊은 물빛 다크 배경 위에, 야광 같은 단일 액션과 레인 색으로 구분되는 선수들. 첫인상은 스톱워치, 능력은 다중 측정.

> 실물 확인: [`design-preview/index.html`](./design-preview/index.html) · [`timer.html`](./design-preview/timer.html)(동작 데모) · [`records.html`](./design-preview/records.html)

---

## 6.1 디자인 원칙

1. **Glanceable.** 1m 떨어진 poolside에서도 읽힌다. 숫자 최우선, 장식 최소.
2. **One obvious action.** 화면에서 가장 크고 밝은 것은 항상 "지금 누를 버튼".
3. **Color = identity.** 각 레인/선수는 고유색. 측정·기록 전반에서 동일 색 유지.
4. **Never color alone.** 색 + 숫자 + 도트/패턴 3중 인코딩(접근성).
5. **Calm dark, vivid action.** 차분한 물빛 위 강렬한 액센트로 시선 유도, 눈부심 저감.

## 6.3 타이포그래피

| 역할 | 글꼴 | 크기/특성 |
| --- | --- | --- |
| 타이머(러닝 클락) | 모노스페이스(`JetBrains Mono`/`SF Mono`/system mono), `font-variant-numeric: tabular-nums` | `clamp(56px, 18vw, 96px)`, 폭 안 흔들림 |
| 스플릿 숫자 | 동일 모노 | 18–22px, tabular |
| 제목/라벨 | 시스템 산세리프(`Inter`/Pretendard/system-ui) | 14–20px, 600 |
| 본문/보조 | 동일 산세리프 | 13–15px, 400–500 |

원칙: **시간은 모두 tabular 모노**로 정렬되게 해 깜빡임/밀림 방지.

---

## 6.4 간격·형태·모션

- 그리드 8px 기준. 컴포넌트 라운드 `--r-card:16px`, 버튼 `--r-btn:20px`.
- **터치 타깃** 최소 64px. **메인 LAP 버튼**: 하단 풀폭, 높이 ≥ 112px, 라운드 28px.
- 그림자 절제(다크에서 글로우로 대체): 액션 버튼에 `0 0 0 1px accent, 0 8px 30px accent33`.
- 모션: 배정 펄스 0.6s ease-out(레인색 글로우 → 소멸), 버튼 press scale 0.98, 100ms. 과한 애니메이션 금지.

## 6.5 핵심 컴포넌트 스펙

| 컴포넌트 | 스펙 |
| --- | --- |
| **러닝 클락** | 상단 중앙. **큰 `MM:SS` + 작은 `.SS`(1/100초, 액센트색)** 로 분리 → 좁은 폭에서도 화면 안에 들어옴. 내부는 ms. |
| **레인 행(측정 중)** | 전체가 **탭 타깃**(방금 벽 찍은 레인 직접 지정). 좌측 레인색 바 + `N번` + 진행 도트 + **최근 스플릿 최대 4개**. 예측 다음 레인은 색 테두리 + `다음` 태그. |
| **START / LAP 버튼** | **화면 하단 풀폭 대형**(엄지 도달). 단일 텍스트(`START`)는 30px·800. LAP은 2줄: `LAP`(32px) + `다음 예측 ▸ N번`(14px). 누름 시 scale 0.98 + 햅틱. |
| **드롭다운(Select)** | 네이티브 화살표 제거(`appearance:none`) + **커스텀 셰브론**(muted, 우측 13px). `--surface`/`--surface-2` 배경, `--line` 보더, 라운드 12px, 높이 44px, 좌패딩 12·우패딩 38. 포커스 시 `--accent` 보더 + 글로우. → 다른 컨트롤과 톤 통일(NFR-11). |
| **보조 버튼** | 실행취소/리셋. 중성 surface-2, 위험은 `--stop`. |
| **칩/배지** | 추천(accent 보더), 맞바꾸기(warn), PB(`--ok`), 저신뢰(warn). 레인색 원형 칩 등. |
| **스플릿 표(배정)** | 슬롯별 행, 세그먼트 열(구간). 셀 탭 편집. |

---

## 6.6 라이트 모드(P1)

실내 형광등 등 환경 위해 라이트 토큰 세트 제공. 배경 `#F2F7FB`, 텍스트 `#0B2233`, 액센트 동일 계열 톤다운. 레인 색은 채도 유지·명도 하향. 기본 테마는 다크.

---

## 6.7 접근성 체크리스트

- [ ] 모든 텍스트 대비 ≥ AA(큰 글자 3:1, 본문 4.5:1).
- [ ] 정보는 색 외 라벨/도트/아이콘 병기.
- [ ] 터치 타깃 ≥ 44px(주요 ≥ 64px).
- [ ] 스크린리더: 버튼 상태("LAP, 레인2 서연에 배정됨") 음성.
- [ ] 모션 줄이기 설정 존중(`prefers-reduced-motion`).
