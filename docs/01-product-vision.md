# 01. 제품 비전 (Product Vision)

## 1.1 한 줄 정의
> **"여러 명을 하나의 스톱워치처럼"** — 코치가 훈련 중 손 하나로 여러 선수의 구간 기록을 정확히 측정하고, 끝나면 자동으로 기록지에 남기는 앱.

## 1.2 해결하려는 문제

전통적인 측정 방식은 다음 한계가 있다.

1. **여러 선수, 손은 둘뿐.** 100y 자유형을 3명이 동시에 출발하면, 각 선수가 25y마다 벽을 찍는 순간이 서로 겹치거나 어긋난다. 단일 스톱워치의 Lap을 누르면 "방금 누른 Lap이 누구의 기록인지"가 사라진다.
   - 예: 1번 아이의 25y에서 Lap → 2번 아이의 25y에서 Lap … 이렇게 하면 **1번 아이의 50y, 75y, 100y 구간은 사실상 측정 불가**.
2. **선수별 버튼은 더 위험하다.** 화면에 선수마다 Lap 버튼을 따로 두면, 훈련 중 긴박한 순간에 **엉뚱한 버튼**을 누른다. 물 튀고, 햇빛 반사되고, 장갑 낀 손으로는 더더욱.
3. **수기 정리의 피로.** 측정한 숫자를 노트/엑셀에 옮기는 일은 반복적이고 누락이 잦다.

## 1.3 제품의 답

- **버튼은 하나.** 일반 스톱워치와 똑같이 `Lap` 하나만 리듬감 있게 누른다.
- **배정은 앱이.** 각 탭을 "지금 벽에 도착할 차례인 선수"에게 **자동 배정**한다. 기존 기록(개인 페이스)을 근거로 예측한다.
- **틀리면 즉석 수정.** 자동 배정이 틀리면, 누른 직후 다른 레인으로 한 번 탭해 재할당. 시계는 멈추지 않는다.
- **끝나면 자동 저장.** 마지막 선수의 Stop이 들어오는 순간, 전 선수 기록이 각자의 기록지로 들어간다.

## 1.4 타깃 사용자

| 페르소나 | 상황 | 니즈 |
| --- | --- | --- |
| **수영 코치 (주 사용자)** | 레인 여러 개, 동시에 8명까지 훈련. 시끄럽고 젖은 환경. | 빠르고 실수 없는 측정, 선수별 기록 누적·비교 |
| **학부모 (보조 사용자)** | 자녀 1~2명 개인 훈련 코칭 | 간단·직관적인 타이머, 성장 추세 확인 |
| **준선수/마스터즈 본인** | 자가 훈련(1명) | 가벼운 스플릿 타이머로도 사용 |

## 1.5 디자인 원칙 (제품 차원)

1. **타이머처럼 직관적, 기능은 다중 측정.** 첫인상은 스톱워치. 학습 비용 0에 가깝게.
2. **Poolside-first.** 햇빛·물·젖은 손·소음 환경에서 동작. 큰 타깃, 고대비, 햅틱·사운드 피드백.
3. **실수 복구 가능.** 모든 측정은 되돌리기/재배정 가능. 측정 중에도, 끝난 뒤에도.
4. **기록은 자동, 신뢰는 수동.** 저장은 자동이되, 저장 직전 확인 화면으로 통제권을 준다.
5. **오프라인 우선.** 네트워크 없이 완전 동작. 동기화는 나중에.

## 1.6 성공 지표 (가설)

| 지표 | 목표 |
| --- | --- |
| 측정 정확도 | 자동 배정 정확률 ≥ 90% (수정 1회 이내로 100% 도달) |
| 측정 후 수기 정리 시간 | 0 (자동 저장) |
| 1세션 측정 실수율 | 세션당 재시작 < 5% |
| 재방문 | 코치 주 3회 이상 사용 |

## 1.7 범위 밖 (Non-goals, 초기)

- 대회 공식 계측/터치패드 연동
- 영상 분석/스트로크 자세 분석
- 멀티 코치 실시간 협업
- 결제/구독 (MVP 이후)
