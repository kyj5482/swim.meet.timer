# 벤치마크: 단일 Lap 버튼 → 다중 레인 자동 배정

실행: `node bench/lap-assignment-bench.mjs`

수영은 **레인**이 있어 length마다 도착 순서가 바뀐다(예: 갈 때 `2-3-4-5`, 올 때 `2-4-3-5`).
또한 **출발 다이브** 때문에 첫 구간이 유난히 빠르다. 이 두 효과를 반영한 시나리오에서
여러 배정 전략의 **정확도(올바른 선수에게 배정된 탭 비율)** 를 측정했다.

## 시나리오 (100 = 4×25, 4레인)

| 코드 | 설명 |
| --- | --- |
| A 순서일관 | length마다 도착 순서 동일 |
| **B 복귀역전** | 갈때 2-3-4-5, **올때 2-4-3-5** (L4가 턴에서 L3 추월) — 사용자 예시 |
| C 난전 | 매 구간 리드가 여러 번 교차 |
| D 초접전 | 0.3초 이내 밀집 |
| E 큰격차 | 레인 간 충분히 벌어짐 |

## 결과 (정확도 %)

```
전략                     A순서일관  B복귀역전   C난전  D초접전  E큰격차    평균
라운드로빈(순서고정)          100     50     25    67    100   68.3
그리디-평균페이스(구 버전)       25     25     25    25     25   25.0   ← 기존
그리디-최근구간              25     25     25    25     25   25.0
단조매칭-평균               100     50     25    67    100   68.3
단조매칭-최근               100     50     42    67    100   71.7
단조매칭-EWMA             100     50     42    67    100   71.7   ← 채택
레인이력(사전배정)           100     97     42    42    100   76.1   ← 순서역전 해결
```

## 해석

1. **기존 그리디(탭마다 최근접)는 25% = 사실상 무작위.**
   한 슬롯이 다음 구간으로 넘어가면 예측 도착시각이 크게 이동해, 인접 슬롯의 탭을
   가로채는 오류가 **연쇄**된다. 선두 한 명조차 안정적으로 추적하지 못한다.

2. **라운드 단조매칭이 정답.** 한 length의 N개 탭을 모아 "예측 도착 순서대로" 정렬·매칭한다.
   직선 위 점-점 최소비용 매칭은 **정렬 후 순서 매칭**이 최적이므로 O(N log N)으로 충분.
   다이브로 첫 구간이 빨라도 *순서*는 보존되므로 영향 없음 → A·E에서 100%.
   같은 세션의 **최근 구간(EWMA)** 으로 페이스를 추정하면 리드 교차에도 가장 강함(평균 71.7%).

3. **사용자가 지적한 복귀역전(B)은 같은-세션 타이밍만으론 50%가 한계.**
   "돌아올 때 L4가 빨라진다"는 건 그 선수의 *미래* 정보라, 슬롯이 자기 과거 스플릿만으로는
   예측할 수 없다. 단, 배정 화면의 **총기록 기반 추천**이 총합은 올바른 선수에 매칭하므로
   "실력 향상(총기록)" 체크는 정상 동작하고, 구간 내부만 약간 혼입된다.

4. **레인 이력 모드(선택)로 복귀역전 97% 해결.**
   코치가 레인↔선수를 사전 지정하면, 각 선수의 **과거 구간 프로파일**(턴·후반 페이스 포함)로
   도착 순서를 예측할 수 있어 B를 거의 해결한다. 다만 초접전(D)·난전(C)에서는 이력의
   불확실성(노이즈)이 실제 격차보다 커서 이득이 사라진다 → 이 구간은 **수동 보정**이 정답.

## 제품 반영

- **기본(익명) 모드**: 그리디 → **라운드 단조매칭(EWMA)** 으로 교체. 25% → ~72%.
- **레인 이력 모드(선택, 정밀)**: 사전 배정 시 과거 구간 프로파일로 순서역전까지 예측.
- **불가피한 모호성(초접전·난전)**: 측정 중 슬롯 칩 재할당 + 배정 화면 맞바꾸기로 100% 보정.

상세 알고리즘은 [docs/03-timer-engine.md §3.3](../docs/03-timer-engine.md) 참고.
